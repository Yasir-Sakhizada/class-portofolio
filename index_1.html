About

Code that ships,
and keeps working.

I'm Yaser, a web developer who cares about the details most people never notice — load times, keyboard navigation, what happens when the API fails. I like building things that are simple to use and straightforward to maintain.

Most of my work is front-end: React, Vue, and plain JavaScript, styled with Tailwind, wired up to real APIs and content systems. I've also spent time on the backend, building small services in Node when a project needed it.

I work with agencies and small teams, usually joining mid-project to help ship something that's stalled, or from the start to set a project up properly.
